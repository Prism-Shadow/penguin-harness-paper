Figure 1: PenguinHarness Unified RSI Experiment Organization Pipeline. The Super Agent orchestrates initialization, training, and held-out testing. It loads the selected RSI skill and snapshots the Target Agent’s initial file state S0. The Target Agent runs benchmark tasks in Docker and produces an execution trace and a task result. The Evaluator scores the task result using a private rubric. The selected RSI method uses the trace and score to propose changes to the Target Agent’s files. Its selection rule keeps the update or restores the previous state. Held-out tests run the same Target Agent with its frozen state S*.
