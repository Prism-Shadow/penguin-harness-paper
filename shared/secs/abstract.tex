Recursive self-improvement (RSI) lets agents refine their instructions and skills from execution feedback. Comparing RSI methods is difficult when each uses a different training loop and benchmark interface. We present \fwname, which packages nine RSI methods as modular skills and pairs them with containerized benchmarks under a common evaluation protocol. A supervising agent orchestrates rollouts, isolated scoring, state updates, and held-out testing. The underlying harness exposes agent state as editable files, loads context on demand, and preserves reusable request prefixes across a session. On six GDPEVO Essential domains, four RSI methods improve held-out scores over the \fwname baseline by 5.83--13.93 points, with the best mean rising from 56.32 to 70.25. Codex adaptations of the same methods gain 1.91--3.43 points over their own baseline under the tested configurations. In these held-out evaluations, \fwname achieves prompt-cache hit rates of 97.42\%--98.24\%.
