Recursive self-improvement (RSI) lets agents refine their instructions and skills from execution feedback. Comparing RSI methods is difficult when each uses a different training loop and benchmark interface. We present \fwname, which packages nine RSI methods as modular skills and pairs them with containerized benchmarks under a common evaluation protocol. A supervising agent orchestrates rollouts, isolated scoring, state updates, and held-out testing. The underlying harness exposes agent state as editable files, loads context on demand, and preserves reusable request prefixes across a session. We describe an evaluation protocol for comparing held-out task performance and prompt-cache reuse across RSI methods and harnesses.
