\section{End-to-End Harness Comparison Under a Fixed Model}
\label{sec:appendix-harness-comparison}
\setcounter{table}{0}

\paragraph{Experimental setup.}
We compare \fwname, DeepSeek Harness (dsh), Pi, and Codex on five containerized benchmark subsets: Data Analysis Bench (Sec.~A), DeepSWE v1.1 (Sec.~B), AutomationBench (Sec.~C), Terminal-Bench-Science 0.1 (Sec.~D), and Terminal-Bench 4.0 (Sec.~E). Each harness uses DeepSeek-V4.1-Flash-1017 at the \texttt{max} reasoning setting and runs each task independently three times. We summarize scores, API cost, and prompt-cache hit rates. The design reserves a comparison with Claude Code under the same conditions.

\paragraph{Results.}
The overall mean scores are 38.00 for \fwname, 38.67 for dsh, 34.00 for Pi, and 30.00 for Codex. \fwname scores 70.00 on both Sec.~A and Sec.~B, including a 16.67-point advantage over Codex on Sec.~B. It has the highest measured cache hit rate at 99.10\%. Its mean input volume is 355 million tokens and its mean API cost is \$4.07 per full 50-task round. The \href{https://github.com/Prism-Shadow/penguin-harness-benchmark/tree/8a507af0329fed8f9a1baf44d1364b438340c78a/experiments/harness-comparison}{run archive} contains the per-subset records. A separate comparison using each harness's default commercial model reported \fwname costs of approximately \(1/70\) of Claude Code's on data analysis and \(1/38\) on coding.
