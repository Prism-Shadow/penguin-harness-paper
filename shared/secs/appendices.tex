\section{End-to-End Harness Comparison Under a Fixed Model}
\label{sec:appendix-harness-comparison}

This protocol compares \fwname, DeepSeek Harness, Pi, and Codex on five containerized benchmark subsets: Data Analysis Bench, DeepSWE v1.1, AutomationBench, Terminal-Bench-Science 0.1, and Terminal-Bench 4.0. Each harness uses DeepSeek-V4.1-Flash-1017 at the \texttt{max} reasoning setting and runs each task independently three times. The evaluation records task scores, API cost, and prompt-cache hit rates.

\section{Context and Cache Microbenchmarks}
\label{sec:appendix-microbenchmarks}

The context microbenchmarks compare the token counts of a skill index and full skill bodies. For tool output, they use a synthetic long log to measure how much text enters the context with and without the configured output limit. The prompt-cache microbenchmarks use an offline simulator to compare request prefixes after state updates, compaction, and resumption.
